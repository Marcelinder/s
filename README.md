# s### Zadanie 9. Pierwsza zmiana i jej opis

1. Na stronie repozytorium proszę kliknąć plik **README.md**, a potem ikonę ołówka (*Edit this file*).
2. Proszę zastąpić treść poniższą (wstawiając własne dane):

```markdown
# Chmura — ćwiczenia

Repozytorium do przedmiotu „Wprowadzenie do przetwarzania w chmurze”.

- Autor: (marcelinder)
- Grupa: (1)

## Czego się tu nauczę
1. Pracy w Google Colab
2. Przechowywania plików w serwisie GitHub
3. Publikowania strony w chmurze
```

3. Przycisk **Commit changes…** → w polu *Commit message* proszę wpisać: `Uzupełnienie README` → **Commit changes**.

**Zatwierdzenie** (*commit*) to zapisany stan plików wraz z opisem: kto, kiedy i po co coś zmienił.
